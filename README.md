# Ajeenky_dy_DSML_20Jan_2025

A nine-day data science and ML course at Ajeenkya DY Patil (from 20 January 2025), ending with an introduction to neural networks.

## Contents

- `day1`, `day2`: Pandas, Matplotlib and Seaborn
- `day3`: feature scaling, linear equation and simple linear regression
- `day4`: decision trees, multiple and polynomial regression
- `day5`: KNN and SVM
- `day6`: bagging, AdaBoost, stacking and random forest
- `day7`: hyperparameter tuning and k-means
- `day8`: ML project (infant health) and a Streamlit app
- `day9`: forward propagation (`for_prop`)

Open the notebooks in Jupyter or Google Colab.
